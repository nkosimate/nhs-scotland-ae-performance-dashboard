# v0.1 — Initial portfolio release

NHS Scotland A&E dashboard combining Power BI, DAX and a Python trend/anomaly visual.

Includes the Power BI report, original Python visual source, parameterised Power Query source, dashboard screenshot, dependency list and data attribution. Reconstructed DAX examples are separately labelled and are not verified model exports.

The owner confirms public-only PHS content and successful refresh/date/board filter checks. Archive integrity and Python syntax checks pass. Independent Python runtime tests and binary-model inspection have not been performed.

Known follow-up work: historical board-code validation and missing-data handling; robust rolling calculations for short date selections; final visual polish and broader calculation/filter testing.

Data: Public Health Scotland, Monthly A&E Activity and Waiting Times. Contains public sector information from Public Health Scotland, licensed under the Open Government Licence v3.0. No standalone CSV is bundled; the PBIX contains imported data. See README for setup and source links.
